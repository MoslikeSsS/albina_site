**Главный CTA:** запись на консультацию.
**Вторичные:** приехать на производство, открыть 3D-планировщик, связаться по телефону 8 (800) 101-36-80.

**Когда страницу открывают:** позднее в воронке — из футера, из блока «О компании» на главной, из ссылки в текстах, из поиска по бренду. ## 2. Посекционная структура

### 2.1 Герой

**Задача:** за 3 секунды дать масштаб и характер компании.

**H1:**
> # Фабрика в Кузнецке, работаем с 1997 года

**Подзаголовок:**
> «Альбина» — мебельная фабрика полного цикла: проектирование, раскрой, фрезеровка, присадка, сборка и отгрузка. Собственный сайт работает с 2007 года — 19 лет, за которые ассортимент менялся, а производство осталось своим.

**Текст справа (или ниже на мобильном):**
> Мебель у нас одна по происхождению и разная по назначению: от компактного комода в прихуюю до модульной кухни. Соединяет их одно — корпус под ваш проём, а не под типовой модуль.

**Быстрые факты (плашка, 4 позиции):**
- `1997` — год основания
- `19 лет` — собственный сайт с 2007-го
- `12` — категорий корпусной мебели
- `Кузнецк` — производство в Пензенской области

**CTA:** **«Записаться на консультацию»** (вторично: **«Приехать на производство»**)

**Триггер:** авторитет.

**UX:** H1 один. Факты — в `<dl>` (термин/значение), а не просто строками, чтобы читались семантически. Фон — фото цеха, реальное производство, `alt`: «Цех раскроя и сборки корпусной мебели фабрики „Альбина“ в Кузнецке».

## 4. UX и доступность

| Что | Требование |
|---|---|
| Контраст | Текст ≥ 4.5:1, подписи к фактам `#57534E` (7.4:1) |
| Типографика | Лонгрид `.prose { max-width: 65ch }`, межстрочный 1.6 |
| Заголовки | Один H1, h2 → h3 без пропусков |
| Таймлайн | Список, а не картинка: вся информация доступна с экрана скип-ссылкой |
| Таблицы | `<caption>`, `tabular-nums`, на мобильном — карточки `<dl>`, без горизонтального скролла |
| Фокус | Кольцо 2–4 px, не перекрывается; фокус на `<main>` после перехода |
| Фото | `alt` описывает операцию или роль, не «фото1»; `width`/`height`, `aspect-ratio`, `srcset` |
| Формы | Видимые подписи, `autocomplete`, валидация по blur, ошибка «причина + как исправить», сводка ошибок, тосты 3–5 с, `aria-live="polite"` |
| Тап-зоны | ≥ 44×44 px, зазор ≥ 8 px |
| Адаптив | 375 / 768 / 1024 / 1440 и landscape; поля растут на широких экранах |
| Данные | Числа в `<dd>` с `tabular-nums`; факты — семантически размечены |
